# Contributing to the documentation

Documentation contributions are welcome.

## Audience

Write for Stationeers players and community server operators. Explain the behavior a reader needs before exposing
implementation details.

## Keep public material safe

Never commit real credentials, enrollment tokens, administrator keys, private host addresses, production inventories,
or unredacted logs. Use names such as `galaxy.example.com`, `example-galaxy`, and `moon-base` in examples.

## Accuracy

- Check current behavior against the relevant implementation repository.
- Mark planned behavior clearly; do not present it as released.
- Avoid exact UI instructions for features still undergoing rapid changes.
- Prefer links to one canonical explanation over copying the same text between pages.
- Use screenshots that do not expose private server details or player information.

## Local preview

The repository is compatible with GitHub Pages and the `minima` Jekyll theme. Markdown files are still readable directly
on GitHub without building the site locally.
